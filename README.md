# GoClock

简体中文 | [English](README.en.md)

常驻 Windows 托盘的小助手，目前有两样本事：

- **桌面提醒**：到点时在屏幕右下角弹出提醒卡片，15 秒后自动关闭，**全程静音**
- **截图**：对标微信截图，框选、标注、钉图、取色，**长截图**（滚动拼接），**识别文字**、**翻译**与**录屏**

## 功能

### 提醒

- **托盘常驻**：启动后只在托盘留一个图标，不占任务栏；开机自启时不会弹出任何窗口
- **右下角弹窗**：无边框卡片贴在工作区右下角，置顶但**不抢焦点**（不会打断正在输入的内容），15 秒倒计时自动关闭
- **随手关掉**：点击卡片任意位置即可关闭，鼠标移上去会变成手型
- **鼠标悬停暂停**：鼠标停在卡片上时倒计时暂停，移开后从暂停处继续（不会重新计时）
- **必须手动关闭**（可按条开关）：开启后，弹窗自动隐藏不算处理完毕，每隔 5 分钟会再弹一次，直到你亲手点掉
- **多条并发**：同时到点的提醒自上而下堆叠，最多同时显示 4 条
- **循环方式**：仅一次 / 每天 / 每个工作日 / 每周（可多选星期几）/ 每月（可多选日期号，支持「月末」）/ 每年 / 每隔 N 分钟
- **开机自启**：写入当前用户注册表，无需管理员权限
- **单实例**：重复启动会唤醒已运行实例的管理窗口，而不是再开一个托盘图标

### 截图

- **全局热键**：默认 `Ctrl+Alt+A`，可在「截图设置」页改；被别的程序占用时托盘会提示
- **冻屏 + 自动识别**：按下热键瞬间冻结整个桌面（多显示器），鼠标悬停自动高亮窗口或控件，单击即选中
- **框选与微调**：拖出选区，八个手柄调整大小，选区内拖动平移，方向键微调 1 像素（Shift 为 10 像素）
- **标注**：矩形、椭圆、箭头、画笔、文字（支持中文输入法），6 种颜色 × 3 档粗细，`Ctrl+Z` 撤销
- **打码**：马赛克或模糊两种样式，可以画笔涂抹，也可以框选一块区域
- **放大镜取色**：光标旁实时显示放大的像素、坐标与颜色值，按 `C` 复制 `#RRGGBB`
- **输出**：双击 / `Enter` 复制到剪贴板（同时提供 PNG 格式，粘到 Office、浏览器不失真）；`Ctrl+S` 另存为；可设置「完成时自动保存」
- **钉图**：把截图置顶钉在桌面上，拖动移动、滚轮缩放、双击关闭、右键复制 / 保存
- **长截图**：在框内滚动鼠标滚轮即自动拼接，也可以让程序自动滚动；吸顶导航、底部输入框、固定侧边栏、滚动条都能正确处理
- **识别文字**：默认用 PaddleOCR（PP-OCRv5）高精度离线识别选区（或钉图、长图）里的文字，像微信一样**直接在图上拖选文字**复制或翻译；也可以换成 Windows 自带的 OCR
- **翻译**：把识别出的文字或任意粘贴的文字交给 Google 翻译，默认中文译成英文、其他语言译成中文
- **录屏**：把选区录成 MP4（H.264，无声音），可暂停，帧率与是否录鼠标指针可设置

## 使用

直接运行 `GoClock.exe`。首次运行会打开管理窗口并写入一条示例提醒，之后启动都只驻留托盘。

| 操作 | 方式 |
|---|---|
| 打开管理窗口 | 左键单击托盘图标，或再次运行 `GoClock.exe` |
| 新增 / 编辑 / 删除 | 管理窗口顶部按钮；双击列表行也可编辑 |
| 快速启停某条提醒 | 勾选 / 取消列表最左侧的复选框 |
| 预览弹窗效果 | 选中一行后点「预览弹窗」 |
| 开机自启 | 管理窗口右上角复选框，或托盘右键菜单 |
| 关闭提醒弹窗 | 点击卡片任意位置；不管它的话 15 秒后自动隐藏 |
| 查看有几条没确认 | 鼠标停在托盘图标上，提示里会写「N 条提醒待确认」 |
| 截图 | 按截图热键（默认 `Ctrl+Alt+A`），或托盘右键菜单 →「截图」 |
| 翻译一段文字 | 先复制文字，再点托盘右键菜单 →「文本翻译」，会直接翻译剪贴板里的文字 |
| 结束录屏 | 点控制条上的「完成」，或托盘右键菜单 →「停止录屏并保存」 |
| 改截图热键、保存目录、录屏与翻译选项 | 管理窗口 →「截图设置」页 |
| 退出程序 | 托盘右键菜单 →「退出」（关闭管理窗口只是隐藏） |

### 截图操作

| 操作 | 方式 |
|---|---|
| 选中整个窗口 / 控件 | 鼠标移上去出现蓝框后单击 |
| 自由框选 | 直接拖动；拖完之后可拖边框、手柄调整，或在选区里拖动平移 |
| 重新框选 | 还没画标注时，在选区外拖动；或右键取消选区 |
| 标注 | 点工具栏上的工具，在选区内拖动；下方一排选粗细与颜色 |
| 打码 | 选「马赛克」工具，下方选「画笔 / 矩形」与「马赛克 / 模糊」 |
| 识别文字 / 翻译 | 「文」打开提取文字窗口，在图上拖选文字（双击选一段、Shift+单击扩展、Ctrl+A 全选），复制或翻译选中部分，「全文」可编辑全部文字；「译」直接翻译全部文字 |
| 录屏 | 点工具栏上的红色摄像机按钮，开始录制选区 |
| 输入文字 | 选「文字」工具后在选区内单击；回车换行，`Ctrl+Enter` 或点别处结束，`Esc` 放弃 |
| 复制到剪贴板 | 双击选区、`Enter`、`Ctrl+C`，或点 ✓ |
| 另存为 | `Ctrl+S`，或点保存按钮 |
| 取色 | 放大镜显示时按 `C` |
| 退出 | `Esc`；右键先取消选区，再按一次退出 |

### 长截图

1. 框好区域，点工具栏上的「长截图」
2. 遮罩消失，区域外留一圈蓝框，旁边出现预览面板
3. 在框内滚动鼠标滚轮（或拖滚动条），画面停稳后会自动接到长图末尾；也可以点「自动滚动」，程序会把鼠标移到区域中央并模拟滚轮，到底自动停下，动一下鼠标或按 `Esc` 也会停
4. 点「完成」打开长图预览窗，可以复制、保存或钉到桌面

几点说明：

- 只支持竖向滚动；往回滚不会被拼进去，回滚后再往下滚可以接着拼
- 一次滚太多、两帧之间没有足够的重叠时，这一帧会被丢弃并提示「滚得太快」，往回滚一点再慢慢滚即可
- 区域里如果有视频、动画，对齐会变困难；有些程序（部分 UWP、远程桌面窗口）不响应模拟滚轮，这类窗口请手动滚动
- 长图最高 30000 像素，到上限会自动停止

### 识别文字与翻译

- 识别在本机完成，**图片不出本机**。有两个引擎，在「截图设置」的「识别引擎」里切换：
  - **高精度（默认）**：PaddleOCR PP-OCRv5 移动版模型，经 ONNX Runtime 推理。对话截图实测错字率 1.2%（系统 OCR 为 14%），
    中英混排时单词之间的空格也能保留。首次使用时自动下载约 33 MB（ONNX Runtime 运行库与检测、识别两个模型）
    到 `%LOCALAPPDATA%\GoClock\ocr\`，版本固定、逐个校验 SHA256：运行库取自 PyPI 上微软发布的 onnxruntime 安装包
    （官方源不通时换腾讯云镜像），模型取自魔搭上的 RapidOCR 仓库。下载跟随「网络代理」设置。
    加载后常驻内存，闲置 1 分钟自动释放
  - **系统自带**：Windows OCR，不用下载、速度快，精度一般；识别语言跟随系统语言（简体中文识别器也认英文和数字）。
    纯英文想更准，可以用管理员权限装英文识别包：`Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"`
- 「文」打开**提取文字**窗口：截图按原样显示，识别出的文字铺一层淡蓝底色。按住左键拖动就能选字，双击选中一段，Shift+单击扩展选区，Ctrl+A 全选；Ctrl+C 或「复制」复制选中部分（没选就复制全部），「翻译」把选中部分送进翻译窗口，「全文」打开可编辑的全部文字。多栏界面（如邮件客户端的三栏）在一栏里往下拖只选中这一栏；长图拖到窗口边缘外会自动滚动
- 高精度引擎下载或加载失败时自动改用系统 OCR，结果窗口底部写明原因；下载失败后 10 分钟内不再重试，免得每次识别都等网络超时
- 长图会切块识别。高精度引擎逐行识别，状态栏显示进度，约 300 行的整页长图十几秒；系统 OCR 会先放大 1.5 倍再识别，几秒钟
- 系统 OCR 的已知短板：只有一两个字的短行、彩色粗体标题偶尔认不全，可以在结果框里直接改
- **翻译会把文字发给 Google**。默认走免 Key 的接口（非官方，可能被限流）；在「截图设置」里填了 API Key
  就改走官方 Cloud Translation 接口，Key 用 Windows DPAPI 加密后保存，只有当前 Windows 账号能解开
- 联网默认跟随系统代理（Internet 选项里的手动代理），也可以在设置页手填代理地址；不支持自动配置脚本（PAC）

### 录屏

1. 框好区域，点工具栏上的录屏按钮
2. 区域外出现一圈红框，旁边是控制条：计时、「暂停 / 继续」「完成」「放弃」，控制条可以拖开
3. 点「完成」后视频保存到截图目录（`GoClock_日期_时间.mp4`），托盘弹出提示，点提示可打开所在文件夹

- 编码用系统自带的 Media Foundation H.264 编码器，有显卡硬件编码就用显卡，不需要另外安装任何东西
- 红框与控制条不会被录进视频；录屏期间按截图热键会提示先结束录屏
- 宽或高为奇数时会自动裁掉 1 像素（H.264 的要求）；本版不录声音

### 循环方式说明

- **每周**：勾选一个或多个星期几
- **每月**：日期号填 `1,15` 这样的列表；填 `月末` 表示当月最后一天（2 月会自动落在 28 或 29 日）
- 每月填 `31` 时，只有 31 天的月份才会提醒，小月自动跳过
- **每年**：选月份 + 日期号，`2 月 29 日` 这类只在闰年触发的日期也能正确推算
- **间隔提醒**：从软件启动后开始计时，每隔 N 分钟提醒一次

### 必须手动关闭

编辑提醒时可以勾选「必须手动关闭」。列表的「关闭方式」一列会标出哪些提醒开了这个选项。

开启之后，弹窗上的提示会变成「点击确认」，因为对这类提醒来说 15 秒倒计时结束只是**暂时隐藏**：

- 你亲手点掉卡片 → 这次提醒就此结束
- 没点，卡片自己消失了 → 5 分钟后原样再弹一次，卡片上会标「第 N 次」，直到你点掉为止
- 期间这条闹钟又到了下次触发时间 → 重新从「第 1 次」开始计，不会堆积成两条

把闹钟停用、删除，或取消这个勾选，等待确认的记录会一并清掉。

待确认的记录**不落盘**：程序退出或重启后就没有了，不会在开机时补弹一堆。

### 关于错过的提醒

电脑休眠或关机期间错过的提醒，如果迟到不超过 30 分钟，开机后会补弹一次；超过则静默跳过，避免开机瞬间涌出一堆弹窗。

## 数据位置

闹钟配置保存在 `%APPDATA%\GoClock\alarms.json`，是可读的 JSON，也可以直接编辑（程序能兼容记事本保存时带的 BOM）。程序设置（截图热键、保存目录、录屏与翻译选项等）保存在同目录的 `settings.json`，其中的 Google API Key 是加密的。同目录下的 `app.ico` 是运行时自动生成的图标缓存，删掉会自动重建。

截图与录屏默认保存到「图片\GoClock」，文件名形如 `GoClock_20261104_153012.png` / `.mp4`。

## 构建

需要 Go 1.26+（`go.mod` 中声明的版本）。**不需要 CGO**，也不需要任何 C 编译器。

```powershell
.\build.ps1
```

或者手动：

```powershell
go run ./tools/genicon                                                        # 生成 assets\icon.ico
go run github.com/akavel/rsrc@v0.10.2 -manifest app.manifest -ico assets/icon.ico -o rsrc.syso
go build -ldflags="-H windowsgui -s -w" -o GoClock.exe .
```

`rsrc.syso` 提供 Common Controls 6 声明（界面才是当前系统的样式）和可执行文件图标。仓库里已经带了一份，只有改动 `app.manifest` 或图标时才需要重新生成。

图标不是二进制素材，而是由 `internal/icon` 用代码绘制出来的，托盘图标与 exe 图标同源。

### 提醒弹窗为什么是自绘的

卡片上的文字没有用标签控件，而是在一个自绘控件里整体画出来的。这么做有两个原因：

- walk 的标签内部是被子类化过的静态控件，它把鼠标消息全部转给了提示条并直接返回，
  标签上的点击事件永远不会触发。文字若用标签铺满卡片，点在文字上就关不掉弹窗。
- 静态控件在布局时按单行文本计算最小宽度，长内容会把整张卡片撑得远超设计宽度。

自绘之后，整张卡片是一个控件，点哪里都能关闭；正文交给 GDI 按可用宽度自动换行，
高度用同一套测量逻辑算出来，卡片宽度恒定为 340。

改动卡片外观时，可以把它离屏渲染成 PNG 直接查看效果：

```powershell
$env:GOCLOCK_PREVIEW_DIR = "D:\preview-cards"
go test ./internal/ui -run TestRenderToastPreview -v
```

渲染走的是弹窗真正使用的测量与绘制函数，因此图片与实际弹窗一致。

### 截图窗口为什么不用 walk 控件

截图遮罩、钉图、长截图面板、长图预览都是原生 Win32 窗口：它们需要全屏双缓冲自绘、高频鼠标、
鼠标穿透的分层窗口，以及按显示器的 DPI 感知，这些 walk 控件都给不了。walk 的消息循环用
`GetMessage(msg, 0, 0, 0)` 分发本线程的全部消息，所以原生窗口直接挂在界面线程上即可，不另开线程。

- **DPI**：程序清单声明的是系统级 DPI 感知，在缩放比例不同的副屏上抓图会被系统换算而发糊。
  截图相关的窗口创建与抓屏都临时切到「按显示器感知 V2」（`capture.WithPerMonitorDPI`），
  拿到的是真实物理像素；清单不改，闹钟界面不受影响
- **抗锯齿**：底图用 GDI 贴图（快），标注用 GDI+ 绘制（抗锯齿）；屏幕显示和导出成图走同一套绘制函数
- **自己的窗口不进截图**：长截图与录屏的边框、面板都设置了 `WDA_EXCLUDEFROMCAPTURE`
- **输入法**：中文输入法开着时，Esc、C 这些键会被输入法截走，所以遮罩、钉图、预览窗平时不挂输入法，
  只在输入文字标注时临时挂上
- **OCR 与录屏不引入第三方 Go 库，也不用 CGO**：WinRT（系统 OCR）、ONNX Runtime 的 C API（高精度 OCR）与
  Media Foundation（编码）都是手写的最小绑定，接口指针一律经输出参数接收，`go vet` 干净；绑定由单元测试与实机测试覆盖
  （编码测试会生成视频并校验 MP4 结构）。ONNX Runtime 运行库不随程序分发，首次使用时下载
- **`//go:uintptrescapes`**：经一层包装函数把 `uintptr(unsafe.Pointer(&out))` 传给系统调用时，包装函数必须加这个标记，
  否则 `out` 留在栈上，栈扩容搬家后系统写回的是旧地址（曾表现为 ONNX Runtime 推理成功、拿到的输出却是空指针）

### 长截图怎么拼

输入是同一块区域在滚动过程中、画面停稳的一系列截图。相邻两帧之间：顶部底部的固定栏不动，
两侧可能有固定的侧边栏，中间区域整体上移了 dy 行。拼接就是求出 dy，再把新帧中间区域最下面的 dy 行接上去。

- 先找出两帧之间变化过的列，排除两侧不动的侧边栏；再从两端剥掉像滚动条的窄列带
- 每行切成若干段分别算指纹，用段指纹投票选出候选位移，再逐行校验，取对上比例最高的那个；
  闪烁的光标、悬停高亮只会弄脏一段，不至于整行对不上
- 纯色段（空白）不参与判断，重叠区里有内容的行太少时宁可丢帧，也不瞎拼
- 单元测试用合成页面（带吸顶栏、底栏、侧边栏、滚动条、大段空白）切帧再拼回去，断言与原页面逐像素一致

### 线程模型

walk 要求所有界面操作固定在同一个系统线程上。因此：

- `main` 一开始就 `runtime.LockOSThread()`
- 调度器持有闹钟的**副本**，通过事件回调把变化交给界面线程处理，两边不共享可变状态
- 后台协程一律通过 `safeSynchronize` 把任务投递回界面线程，该函数会跳过已销毁的窗口
- 弹窗的倒计时由弹窗管理器统一驱动，只向生命周期最长的主窗口投递任务
